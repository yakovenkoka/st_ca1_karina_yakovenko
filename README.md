This project is about building a Convolutional Neural Network (CNN) for the image classification part of a self-driving car.

The goal is to classify images into 24 different classes using the CIFAR-10 and CIFAR-100 datasets.

I loaded and combined the datasets, explored the images, and preprocessed them before training. I then built and tested different CNN models and changed the training settings to improve accuracy and reduce overfitting.

## How to Run

Run the project using:

```bash
uv run main.py
```
